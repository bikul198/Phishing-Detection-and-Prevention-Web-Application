# Phishing Detection and Prevention Web Application

This project is a web-based tool that helps users detect and prevent phishing attacks by analyzing suspicious URLs using a machine learning model.

**Name:** Bikul  
**GitHub Username:** [bikul198](https://github.com/bikul198)

## 📌 Project Description

Phishing is a major cybersecurity threat that targets users by tricking them into clicking malicious links. This project provides a user-friendly web interface where users can input URLs and get immediate feedback on whether the link is safe or potentially a phishing threat.

The detection system is powered by a machine learning model built with Python and scikit-learn, and deployed via a Flask-based backend. The frontend is built using HTML, CSS, and JavaScript.

## 🚀 Features

- URL input and validation
- ML model to classify URLs as safe or phishing
- Responsive frontend UI
- Instant feedback with user-friendly result display
- Error handling for invalid input

## 🧰 Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Machine Learning:** scikit-learn, pandas, numpy
- **URL Feature Extraction:** re, urllib
